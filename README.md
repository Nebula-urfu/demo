# YKit: демо-прототип на Nuxt

Демо без реальной работы: один проект Nuxt (интерфейс и сервер), SQLite, принимается любой вход, ИИ, Documents, Reference Data и Notifications подделаны («ДЕМО»). Интерфейс сделан по макету Figma. Подробности: `docs/SPEC.md`, решения: `docs/DECISIONS.md`.

## Запуск (fish)

```fish
npm install
npm run dev                                   # http://127.0.0.1:3000
env DEMO_AI_DELAY_MS=0 npm run dev            # мок ИИ без задержки
```

Переменные: `DEMO_AI_DELAY_MS` (по умолчанию 1500), `DEMO_DB_PATH` (по умолчанию `data/demo.db`), `DEMO_RESET_ON_START` (по умолчанию `true`).

## Проверка

```fish
npm test                  # vitest, tests/smoke.test.ts
npx nuxt typecheck
bash scripts/demo.sh      # сценарий API против запущенного сайта, печатает DEMO OK
```

`scripts/demo.sh` требует `curl` и `jq`.

## Что показывать (5 минут)

Откройте http://127.0.0.1:3000 в двух окнах (обычное и приватное).

1. Окно 1: «Войти как житель», «Подать заявку»: фото, описание «Протечка кровли над подъездом», подъезд. Статус «Принята».
2. Окно 2: «Войти как сотрудник», открыть заявку: ожидание ИИ, триаж и ТЗ, «Подтвердить маршрут».
3. ТЗ: ответы на вопросы, правка, «Сохранить», «Отправить на проверку».
4. Переключатель роли в шапке → «Проверяющий»: открыть задачу, «Вернуть на доработку» с комментарием. У сотрудника появится новая версия ТЗ с комментарием; отправить снова, проверяющий утверждает.
5. Сотрудник, шаг «КП и НМЦ»: «Подготовить письмо», три КП, сравнение (подсвечены расхождения), «Рассчитать», «Отправить на проверку». Проверяющий утверждает.
6. Шаг «Документы»: «Выбрать» победителя, затем «Пакет», «Отправить на проверку». Проверяющий утверждает: заявка «Выполнена» (у жителя тоже).
7. «Демо-панель»: журнал событий (задания ИИ, уведомления). У проверяющего «Журнал согласований».

Сбой ИИ: заявка с описанием, содержащим `[fail]`, один раз даст «Сбой ИИ» и кнопку «Повторить». Аварийная заявка: «Прорыв трубы, затопило подъезд».

## Устройство

`app/` интерфейс; `server/api/v1` эндпоинты (27 операций контракта и `dev/*`); `server/domain` бизнес-логика; `server/gateway` интерфейсы `AiGateway`, `DocumentsGateway`, `ReferenceGateway`, `NotificationsGateway`; `server/mock` их реализации и фикстуры; `server/db` SQLite. Контракт: `contract/core-api.openapi.yaml`. Сервер слушает только `127.0.0.1`.
