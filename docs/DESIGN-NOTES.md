# DESIGN-NOTES: выписки из макета Figma

Файл: https://www.figma.com/design/AqhhX0BeIoygkaIjKa9WXR/YKit (прочитан через Figma MCP, 24.10.2026). Снимки лежат в `design/`.

## Страницы
- «Прототипирование» (0:1): около 50 фреймов экранов, у каждого мобильная (390) и десктопная (1280) версия; тёмные варианты; сбоку заметки «Для фронтенда».
- «UX-схема» (5:2): дорожки Житель, ИИ-агент, Сотрудник УК, Проверяющий.
- «Брендинг» (1:161): логотип, цвета, типографика.

Шрифты: Unbounded (SemiBold, Medium, Regular) для заголовков, Onest Regular для текста. Размеры текста: 16 (Body), 14 (Small), 12 (Caption). Лицензия обоих OFL, ставятся локально пакетами `@fontsource-variable/*`, внешних шрифтов нет. Все значения в `app/assets/css/main.css` (`@theme`).

## Компоненты
Кнопки-капсулы (основная синяя, вторичная белая с рамкой), пилюли-фильтры, бейджи статуса (В работе, Утверждено, Черновик, Срочно), поле ввода с рамкой, карточки со скруглением около 24 px, шапка-капсула с логотипом, навигацией и переключателем роли, синий блок-приветствие с большим знаком Y, плитки с цифрами, пилюли шагов «1. Триаж … 5. Пакет», зона загрузки с пунктирной рамкой, таблицы с серой шапкой. На телефоне: нижняя навигация, ряды пилюль в горизонтальном скролле, таблицы в карточки, кнопки на всю ширину.
